## ymtui 1.0.0

Первый релиз терминального клиента Яндекс Музыки.

- Поиск треков, исполнителей и альбомов.
- «Моя волна», любимые треки, плейлисты и очередь.
- Управление клавиатурой и мышью, поддержка русской раскладки.
- Установка на Windows одной командой, без Rust и прав администратора.

### Установка

Откройте PowerShell и выполните:

```powershell
irm https://github.com/size-prog/Ymtui/releases/latest/download/install-online.ps1 | iex
```

Затем войдите в аккаунт Яндекс Музыки и запустите плеер:

```powershell
ymtui --login
ymtui
```

Для установки вручную скачайте `ymtui-windows-x64.zip`, распакуйте его
и запустите `install.cmd`. После установки откройте новый терминал.

В пакет включена libmpv. Поддерживается Windows x64.
Для проверки без аккаунта: `ymtui --demo` (без звука).
